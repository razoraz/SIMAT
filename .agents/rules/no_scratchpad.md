# Rule: Strict No Browser Subagent & No Scratchpad

1. **Do NOT invoke `browser_subagent`**: Never automate, inspect, or navigate browser sessions unless the user explicitly tells you to do so in the chat.
2. **Do NOT generate scratchpad files**: Never create `scratchpad_*.md` files or planning scratch files in scratch/temp directories.
3. **Direct Code Execution**: Directly edit code, run terminal commands, and provide clear concise responses.
